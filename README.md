# Taller de Git & GitHub 

Ejercicio final del taller de Git & GitHub — Club de Programación, ESTl UAEH.

## Instrucciones
1. Haz un **Fork** de este repositorio (botón arriba a la derecha)
2. Clónalo a tu computadora: `git clone <url-de-tu-fork>`
3. Abre `bienvenida.md` y agrega tu nombre en la lista
4. Guarda, haz commit y push a tu fork
5. Abre un **Pull Request** hacia este repositorio original
